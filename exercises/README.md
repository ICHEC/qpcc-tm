# CT-4100 exercises

Place the course's Jupyter notebooks in this directory and commit them to the
repository. Use descriptive filenames such as `exercise-01-introduction.ipynb`.

During deployment, every `.ipynb` file in this directory is converted to a
standalone HTML page. The website homepage automatically adds **View** and
**Download** links for each notebook.

Notebook cells are not executed during deployment. Save the notebook with its
outputs if charts, tables, or computed results should appear on the website.
